# 模型列表紧凑布局与折叠编辑

## 预期结果

在 OpenCode 模型表单中一次性完成专用‘模型列表’文案、模型基础/成本/限制字段的响应式紧凑网格，以及 Options 和 Variants 的独立折叠、实时计数、折叠态添加后展开和紧凑编辑布局。保留全部既有字段与各层动态增删能力，并通过组件测试验证可访问状态、配置形状及表单与原始 JSON 双向同步，不触碰 API Key 数据流或配置持久化契约。

## 实施清单

- [ ] 在 `src/i18n.ts` 的全部现有支持语言中增加 OpenCode 专用“模型列表”翻译键，仅在 OpenCode 模型区块标题使用，并保持通用 `models` 键及其调用方不变。
- [ ] 将模型基础字段、成本字段和限制字段重排为紧凑响应式网格，收紧模型卡片内边距、字段间距与分区间距；桌面优先并排，窄屏按现有语义顺序降列且不隐藏模型新增、删除或编辑入口。
- [ ] 为每个模型的 Options 与 Variants 分别维护组件本地展开状态，初始均折叠；标题行显示名称、实时条目数、独立展开状态和添加入口，并提供准确的可访问名称与 `aria-expanded`。
- [ ] 调整 Option 与 Variant 添加行为，使折叠态添加后对应区块自动展开且新条目立即可编辑；计数始终从当前表单数据派生，能响应表单增删和 JSON 反向同步。
- [ ] 将 Options 改为保留键名、类型、值和删除操作的紧凑行布局，将 Variants 改为保留名称、内部 Options 及各层新增删除操作的紧凑分组布局，不改变既有更新处理函数和配置形状。
- [ ] 扩展组件、i18n、配置和集成测试，覆盖专用标题、默认折叠、独立展开/收起、实时计数、折叠态添加、各层动态增删、可访问状态以及表单与原始 JSON 双向同步。

## 验收标准

- [ ] OpenCode 模型区块显示专用“模型列表”文案，全部现有支持语言均有对应资源，通用 `models` 键和其他界面文案保持不变。
- [ ] Options 与 Variants 初始独立折叠并显示准确数量，可分别展开和收起；折叠态添加后对应区块展开，新条目立即可编辑且计数同步。
- [ ] 模型基础、成本和限制字段在桌面形成紧凑网格，在窄屏按可读顺序重排；字段、文字、计数和操作按钮不重叠，必要操作不被隐藏。
- [ ] Options 的键名、类型、值与删除，以及 Variants 名称、内部 Options 和各层新增删除能力全部可用。
- [ ] 折叠状态和计数不写入配置，表单与原始 JSON 双向同步、解析、校验、合并及未知字段保留语义不变。
