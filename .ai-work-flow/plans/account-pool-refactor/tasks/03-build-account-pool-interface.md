## 预期结果

将卡片网格重建为服务商式纵向账号列表，展示规定字段并保留编辑、排序、启停和删除；提供当前搜索结果内的选择、全选、批量禁用及带数量确认的批量删除；将新增账号组织为不修改 URL 的模块内独立视图，通过一次请求保存完整配置。验收以操作不跨组或包含隐藏账号、无选择不可执行、批量成功刷新并清空选择而失败保留选择，以及新增取消不写入、成功返回列表、失败保留草稿和既有单账号行为不回归为准。

## 实施清单

- [ ] 参考 `ServiceProviderList.tsx` 的信息层级，将账号卡片网格替换为稳定宽度的纵向账号项；每项展示名称、API 地址、认证方式、上游协议、自定义标签、模型映射和备注，并提供清晰的启用状态与空状态。
- [ ] 保留每个账号的编辑、上移、下移、启用/禁用和删除入口；动作仍调用既有单账号 facade，排序边界和禁用状态应正确禁用控件，OAuth 账号继续只展示其可用配置而不出现新增 OAuth 能力。
- [ ] 为当前可见账号项增加复选框，建立单项选择和全选/取消全选交互；全选只写入当前分组当前搜索结果的 ID，无选择时不呈现或禁用批量禁用和批量删除命令。
- [ ] 实现批量禁用：从已校正选择集合构造显式账号 ID 数组；仅在后端成功后重新 bootstrap 并清空选择，失败时显示错误且保留选择。已禁用账号可被包含在请求中。
- [ ] 实现批量删除：二次确认文案必须显示待删除账号数量，取消不调用确认或删除命令且保留选择；确认后使用集合绑定令牌执行删除，成功刷新并清空选择，失败保留选择。
- [ ] 保持 `viewMode`、`detailMode` 和 `selectedAccountId` 的模块内部切换，将添加账号作为无 URL 变化的独立创建视图；返回/取消仅回到列表，不触发创建请求或隐式保存。
- [ ] 在创建视图补齐分组、标签和额度阈值控件，与名称、API 地址、API Key、认证方式、上游协议、备注、模型映射和价格配置一起构造一次完整创建请求；默认分组选取有效默认组，阈值空值表示继承。
- [ ] 创建成功后清理敏感 API Key 状态、返回列表并重新 bootstrap；创建失败停留当前视图，保留全部非敏感草稿和可理解错误。编辑流程继续使用现有专属更新、映射和价格命令，不改成创建命令。
- [ ] 在 `src/i18n.ts` 补齐中英文搜索占位、全选、已选数量、批量禁用、批量删除数量确认、新增字段、空状态和错误文案；所有 icon-only 操作保留可访问名称或 tooltip。
- [ ] 检查窄宽度布局：分组 tabs 可滚动，账号项信息和动作可换行，选择工具栏与确认弹窗不遮挡，模型映射/价格表单保持可用且不导致页面横向内容重叠。

## 验收标准

- [ ] 账号池使用纵向列表并展示规格要求的全部字段，空状态提供添加入口；不引入服务商图标、历史回滚、JSON 编辑、激活等范围外能力。
- [ ] 单账号编辑、排序、启停和删除继续工作，动作只影响目标账号；其他 AI 路由网关 tabs 行为不回归。
- [ ] 单项选择、全选和批量请求均不跨当前分组，不包含被当前搜索隐藏的账号；无选择时批量动作不可执行。
- [ ] 批量禁用和删除成功后重新加载并清空选择；失败保留选择。批量删除确认显示准确数量，取消时不发任何删除请求。
- [ ] 添加账号进入模块内独立视图且 URL 不变；取消或返回不写入，保存仅发出一次包含分组、标签、阈值、连接、备注、映射和价格的创建请求。
- [ ] 创建成功返回列表并显示刷新后的账号；创建失败保留草稿和错误，既有编辑流程仍按原命令保存连接、映射及价格。
- [ ] 在窄宽度下 tabs、纵向账号项、选择工具栏、创建表单和确认弹窗无文字截断导致的不可操作状态或互相重叠。
