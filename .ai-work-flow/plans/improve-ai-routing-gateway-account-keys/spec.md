# 改进 AI 路由网关账号与密钥管理

## Spec Metadata

- plan-id: `improve-ai-routing-gateway-account-keys`
- status: `approved`

## Problem Statement

AI 路由网关需要具备独立的上游 OpenAI API Key 账号管理能力，以及可安全管理、分组授权和审计使用情况的网关密钥能力。当前体验需要与应用既有的 AI 终端服务商管理交互保持一致性，同时严格保持两套数据相互独立。

## Goals and Success Criteria

- 用户可在 AI 路由网关中新增和编辑 OpenAI API Key 账号，并配置其连接与认证信息。
- 用户可查看账号模型映射、账号级价格覆盖和账号卡片关键信息。
- 用户可创建、查看、复制、分组关联、禁用和删除网关密钥，并在列表中获得按当前应用时区统计的使用数据。
- 网关运行时，应用顶部右上角显示与既有协议路由和 SSH 隧道风格一致的状态图标。
- 账号池与 AI 终端服务商的数据、生命周期和配置始终彼此独立。

## Users and User Stories

- 作为管理员，我需要新增一个 OpenAI API Key 账号并编辑密钥、API 地址、认证方式和上游协议，以便为网关配置可用上游。
- 作为管理员，我需要在账号详情中查看预置模型、模型名称映射和价格，以便确认路由成本配置。
- 作为管理员，我需要辨认 API Key 与既有 OAuth 账号，并在卡片上快速查看 API 地址和模型映射，以便管理账号池。
- 作为管理员，我需要将一个网关密钥关联到多个分组，并在选择发生变化后立即生效，以便控制访问范围。
- 作为管理员，我需要安全复制完整网关密钥，同时避免在列表中暴露完整值，以便兼顾可用性和密钥保护。
- 作为管理员，我需要查看密钥的状态、生命周期和近期使用量及费用，以便审计和治理网关访问。

## Functional Requirements

- 账号池复用 AI 终端服务商的卡片呈现和专属编辑页交互模式，但使用独立账号数据。
- 首期账号池仅允许新增和编辑 OpenAI API Key 账号。
- OpenAI API Key 账号必须支持编辑密钥、API 地址、认证方式和上游协议。
- OAuth 账号在首期不得提供新增或重新登录能力；已存在的 OAuth 账号必须可展示，并带有 OAuth 标签。
- 账号详情必须预置 OpenAI 官方模型。每个预置模型的默认外部模型名必须等于官方模型名。
- 账号详情中的价格默认使用内置官方价格，并允许针对单个账号覆盖价格。价格字段为每百万 Token 的 input、output、cache read 和 cache write。
- 账号卡片必须展示 API 地址、API Key 或 OAuth 账号类型标签，以及模型映射信息。
- AI 路由网关仅在运行时于应用顶部右上角显示状态图标；图标的状态表达与应用既有协议路由和 SSH 隧道保持一致。
- 新建网关密钥必须加密保存完整值。密钥列表只能展示前 6 位和后 6 位，中间内容不得显示。
- 网关密钥复制操作必须复制可实际使用的完整密钥，而非脱敏显示值。
- 用户可以将一个网关密钥关联至多个分组；在列表中变更分组选择后，关联关系必须立即保存。
- 网关密钥列表必须展示创建时间、过期时间、状态、今日和近 30 天的请求次数、Token 数及费用。
- 今日和近 30 天统计必须使用应用当前时区的日期边界。
- 网关密钥必须支持禁用和删除。删除必须沿用 revoke 语义并保留历史记录。

## Non-Functional Requirements

- 完整网关密钥不得在列表、常规展示文本或日志型界面中明文暴露。
- 脱敏展示必须稳定保留前后各 6 位，且不得因复制、分组修改、禁用或删除操作泄露中间字符。
- 账号价格覆盖仅影响对应账号的价格配置，不得改变预置官方默认价格或其他账号配置。
- 账号池操作不得读取、写入或同步 AI 终端服务商的数据。
- 统计数据的日期解释必须与应用当前时区一致，避免同一时刻在不同列表统计口径下产生不一致结果。

## Scope

范围内：

- AI 路由网关的独立账号池卡片、账号详情编辑交互和 OpenAI API Key 账号配置。
- 已有 OAuth 账号的展示与 OAuth 标签。
- OpenAI 官方模型预置、模型名称默认映射、官方默认价格和账号级价格覆盖。
- 运行时网关状态图标。
- 网关密钥的加密保存、脱敏列表展示、完整值复制、多分组关联、即时保存、使用统计、禁用和 revoke 删除。

## Interfaces and Data

- 账号池数据与 AI 终端服务商数据是两套独立数据集；两者不共享账号记录、编辑结果或同步机制。
- OpenAI API Key 账号包含密钥、API 地址、认证方式、上游协议、模型映射和可选的账号级价格覆盖。
- OAuth 账号可作为既有账号记录展示，其类型通过 OAuth 标签标识；首期不提供创建或重新授权接口。
- 模型映射以 OpenAI 官方模型为基础，默认外部模型名等于对应官方模型名。
- 价格以每百万 Token 计量，分别包含 input、output、cache read 和 cache write。
- 网关密钥包含完整加密值、脱敏展示值、关联分组、创建时间、过期时间、状态和使用统计。完整值仅用于安全保存与复制可用密钥，不作为列表展示数据。
- 密钥使用统计包括按应用当前时区计算的今日和近 30 天请求次数、Token 数与费用。

## Failure Modes

- 当网关密钥仅有脱敏值可用于展示时，复制操作不得返回脱敏值或不完整值；无法取得可用完整值时，操作必须明确失败且不得伪造成功。
- 当分组关联保存失败时，列表不得将未保存的选择误表示为已生效。
- 当账号为 OAuth 类型时，界面不得暴露新增 OAuth 或重新登录入口。
- 当账号未配置价格覆盖时，必须继续使用内置官方默认价格，而非显示为空或使用其他账号的覆盖值。
- 当密钥被禁用或 revoke 删除时，其后续可用性必须与状态一致；历史使用记录仍须保留可供审计。
- 当网关未运行时，顶部右上角不得误显示运行状态图标。

## Acceptance Criteria

- 新增 OpenAI API Key 账号时，用户可以保存密钥、API 地址、认证方式和上游协议；编辑同一账号后，更新内容可再次查看。
- 账号池的卡片和专属编辑页交互与 AI 终端服务商的对应模式一致，但在任一侧新增或编辑账号均不会出现在另一侧。
- 已有 OAuth 账号显示 OAuth 标签，且界面没有 OAuth 新增或重新登录操作。
- 任一账号详情展示 OpenAI 官方预置模型；未改动映射时，外部模型名与官方模型名相同；未覆盖价格时显示内置官方价格，覆盖后仅该账号使用覆盖的 input、output、cache read、cache write 价格。
- 账号卡片同时可见 API 地址、账号类型标签和模型映射。
- 网关运行时，应用顶部右上角出现与协议路由或 SSH 隧道同类样式的状态图标；网关未运行时不显示该运行状态。
- 新建网关密钥在列表中仅显示前后各 6 位；通过复制操作取得的值是完整、可用的密钥。
- 一个密钥可关联多个分组；每次在列表中变更选择后，刷新或重新进入列表仍显示已保存的关联结果。
- 密钥列表显示创建时间、过期时间、状态，以及按应用当前时区计算的今日和近 30 天请求次数、Token 数和费用。
- 禁用后的密钥不可继续作为启用密钥使用；删除后密钥按 revoke 处理且历史记录仍可保留和查询。
- 账号池与 AI 终端服务商之间不存在数据同步：账号、模型映射、价格覆盖和操作结果均不跨域复制。

## Compatibility and Migration

- 旧网关密钥不要求兼容、迁移或继续可用；用户将删除旧密钥并重新创建。
- 新密钥必须按本规格加密保存完整值，并使用前后各 6 位的脱敏展示规则。
- 既有 OAuth 账号仅保留可展示兼容性，不获得首期新增或重新登录能力。
- 本次变更不迁移、不合并也不同步 AI 终端服务商与账号池之间的任何数据。

## Out of Scope

- 新增 OAuth 账号、OAuth 重新登录或授权流程。
- 账号池与 AI 终端服务商之间的数据同步、导入、复制或双向更新。
- 旧网关密钥的格式兼容、密文迁移或继续使用。
- 除 OpenAI API Key 账号以外的新上游账号类型创建能力。
- 超出今日和近 30 天范围的新增统计周期或改变应用当前时区设置。

## Assumptions

- 应用已有可参照的 AI 终端服务商卡片和专属详情编辑页交互，以及协议路由和 SSH 隧道状态图标表达。
- 应用已有可参照的密钥 revoke 历史保留语义和当前时区定义。
- OpenAI 官方模型与内置官方价格可作为账号详情的初始默认数据来源。
- 已有 OAuth 账号数据在账号池中可被识别为 OAuth 类型并安全展示。
