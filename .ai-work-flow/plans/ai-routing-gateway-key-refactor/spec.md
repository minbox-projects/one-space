## 问题陈述

现有网关密钥页面位于 `src/components/AiRoutingGateway/index.tsx`，创建表单内嵌且密钥列表不是表格，无法在展示分组内高效维护、组合筛选或对比用量。密钥尚无独立展示分组，也不能安全、可防重地批量转换为 AI 终端各工具的服务商。网关和服务商为独立数据域，当前不存在转换关系或 IPC。

## 目标与成功标准

将网关密钥页重构为可在展示分组中创建、编辑、查询和维护的表格工作流，并保留既有认证、加密、一次性明文、复制、重新生成、路由账号分组授权、模型授权及统计能力。

成功标准：

- 用户可在当前展示分组内以弹框创建或编辑密钥，并在创建后仅一次查看和复制明文。
- 用户可准确查看每个密钥今日及近 30 个自然日的 token 和费用；存在无法完整计费的记录时费用明确为不可计算。
- 列表只暴露脱敏密钥，支持名称、脱敏值、前缀和后缀的组合查询。
- 用户可批量选择 Claude、Codex、Gemini、OpenCode 转换为独立服务商记录；后端防止重复和半成功，删除服务商后允许重新转换。

## 用户与用户故事

- 本地桌面应用用户需要创建网关密钥，为其指定展示分组、过期时间、路由账号分组授权和模型授权，并复制创建时给出的完整密钥。
- 用户需要切换独立展示分组，按文本和状态筛选当前分组的密钥，比较用量、费用和有效性。
- 用户需要启用、停用、编辑、删除或重新生成密钥，而不会在普通列表中意外看到已软删除记录。
- 用户需要将一个网关密钥转换为多个终端工具的服务商，并选择是否统一激活，同时明确哪些工具已转换不可重复选择。
- 后续实现与测试人员需要稳定的迁移、IPC、状态、事务和安全契约。

## 功能需求

### 密钥创建、编辑与既有操作

- 创建和编辑均使用弹框。创建表单维护名称、展示分组、过期时间、路由账号分组授权和模型授权。
- 创建成功后返回一次性完整明文，界面提供显式复制；列表、查询响应和常规详情不得包含完整明文。
- 编辑不得修改密钥值。重新生成是独立操作，继续遵守一次性明文和 RootKey 加密约束。
- 操作列使用带工具提示的图标按钮，支持启用/停用、编辑、删除和转为服务商。
- 删除采用软删除：立即失效、默认隐藏，保留历史请求日志、用量和审计数据。

### 展示分组

- 新增密钥专属展示分组；每个密钥恰好归属一个展示分组。
- 分组交互和生命周期参考 SSH 隧道分组：支持切换、默认组、创建、重命名和删除。
- 默认组不可重命名或删除。删除自定义组时，该组全部密钥必须原子迁移至默认组。
- 所有存量密钥在迁移后归属默认组。
- 此展示分组与既有可多选的路由账号分组授权互不替代；后者继续作为密钥授权配置。

### 表格、状态与筛选

- 列表必须使用 table，列顺序严格为：名称、API 密钥、分组、用量、过期时间、状态、创建时间、操作。
- API 密钥列只显示脱敏值。
- 用量列同时显示今日和近 30 个自然日的 `total_tokens` 与 `estimated_cost_usd`；任一所需费用不完整时，相应费用显示“不可计算”，不得伪造零值或部分总价。
- 默认列表排除软删除记录。状态筛选仅含全部、活跃、已停用、已过期。
- 有效状态计算：软删除或撤销记录不可作为常规状态展示；未撤销记录中 `expires_at <= 当前时间` 为已过期，优先于 `enabled`；未过期且 `enabled=true` 为活跃，否则为已停用。
- 单一文本框按名称、脱敏密钥、密钥前缀或后缀匹配。文本条件与状态条件以 AND 共同作用于当前展示分组。

### 服务商转换

- 转换弹框可多选 Claude、Codex、Gemini、OpenCode，统一“是否激活”开关默认关闭。
- 每个选择的工具创建一个独立 `ServiceProviderRecord`，记录单属一个 tool，名称继承网关密钥名称，API 密钥使用后端解密后的完整网关密钥。
- 系统生成网关 `base URL` 和合法工具标识，并处理名称或标识冲突；前端不提交可信的生成值。
- 开启统一激活时，Claude、Codex、Gemini 分别替换该工具当前 active 服务商；OpenCode 追加 active 服务商。关闭时新记录遵循非激活状态。
- 已转换工具在弹框中不可选择，但该禁用仅是交互提示；后端必须校验。

## 非功能需求

- 所有 IPC 保持 typed API 风格，Rust command 在应用运行时显式注册。
- 关键写操作具备事务性和并发安全性，重复请求或并发转换不得产生重复服务商或孤立关系。
- 统计查询按密钥聚合，并限制近 30 个自然日窗口；时间边界使用后端统一的当前时间。
- 前端在加载、空列表、提交中、成功和失败状态下提供可恢复反馈，提交中不得重复创建或转换。
- 数据库约束而非仅前端状态承担唯一性、归属及关联完整性。

## 范围

包含：前端网关密钥页和弹框、独立展示分组、Tauri IPC、Rust 业务逻辑、SQLite 迁移、服务商转换关系、用量展示及相关前后端测试。

## 接口与数据

### 现有数据与新增模型

现有 `ai_gateway_api_keys` 保留名称、脱敏构成、加密密钥、`enabled`、`expires_at`、`revoked_at`、`last_used_at`、`created_at` 及既有授权关系。

新增或扩展的数据契约：

- 密钥展示分组实体：包含稳定 ID、名称、默认组标记、创建与更新时间；默认组唯一。
- `ai_gateway_api_keys` 增加非空展示分组外键。迁移先建立默认组，再将存量密钥回填至该组。
- 网关密钥至服务商转换关系实体：至少包含网关密钥 ID、工具标识和服务商记录 ID。对 `(gateway_key_id, tool)` 建立唯一约束；关系中的服务商记录单属对应工具。
- 服务商删除必须在同一一致性边界内删除或解除转换关系，使该工具可再次转换。
- 列表项返回脱敏密钥、展示分组、状态和两个用量窗口；完整密钥不在列表 DTO 中。

### IPC/命令契约

在 `src/lib/aiRoutingGateway.ts` 定义 typed 调用，并由 `src-tauri/src/ai_routing_gateway/commands/mod.rs` 提供对应命令、在 `src-tauri/src/app_runtime/run_app.rs` 注册。命令覆盖：

- 展示分组列表、创建、重命名、删除及当前组密钥查询。
- 密钥弹框所需的创建、编辑、显式复制/获取一次性明文、重新生成、启用/停用、软删除和授权更新。
- 带 `group_id`、文本查询、状态筛选及分页/排序约定的列表查询；响应含今日及近 30 日用量和费用可计算状态。
- 读取一个密钥可转换工具集，以及提交多工具转换与统一激活开关。

写命令的输入不得携带明文密钥以外的派生服务商 API key、系统 `base URL` 或可信工具标识。服务端从受控枚举生成并校验这些值。

## 失败模式

- 名称、分组、过期时间、授权或工具选择无效时，命令返回可展示的验证错误且不写入部分数据。
- 默认组重命名或删除必须被拒绝；删除不存在或不可删除的分组不得迁移任意密钥。
- 查询指定已删除、不存在或无权访问的展示分组时返回明确错误或空结果，且不得泄露其他组密钥。
- 已过期、已撤销、已软删除或不存在的密钥不得转换、启用或作为有效凭据；后端返回状态冲突。
- 转换中若解密、服务商创建、激活调整或关系写入任一步失败，整个事务回滚，不得残留服务商、关系或激活状态变更。
- 唯一约束冲突应转换为“该工具已转换”的稳定错误；客户端刷新可转换工具集。
- 服务商删除与关系解除失败时整体回滚，避免服务商已删除但关系仍阻止重转，或关系已删但服务商仍存在。
- 费用数据缺失或不完整不是查询错误，响应以不可计算语义表达。

## 验收标准

- 创建、编辑和重新生成均符合弹框及明文边界；编辑不改变密钥值，创建/重生成后明文只在显式结果中可复制。
- 展示分组可创建、切换、重命名和删除；默认组不可改删，删除自定义组后其密钥全部迁入默认组，存量密钥也已回填。
- 表格列和顺序完全符合要求，列表只显示脱敏密钥，并正确显示今日/近 30 日 token 与费用或不可计算提示。
- 文本查询与状态筛选只在当前展示分组内以 AND 生效；状态优先级和过期边界正确，软删除密钥不出现在默认列表。
- 操作列提供有工具提示的图标操作；软删除立即失效且保留历史日志、用量和审计。
- 转换弹框支持四种工具多选、默认不激活和已转换工具禁用；每个工具得到独立服务商记录。
- 后端拒绝重复转换和无效密钥转换；多工具转换原子完成，删除转换生成的服务商后可重转。
- 激活开启时前三种工具正确替换单个 active，OpenCode 正确追加 active；关闭时不改变既有 active。

## 兼容性与迁移

- 保留现有密钥认证、RootKey 加密格式、一次性明文语义、复制、重新生成、路由账号分组授权、模型授权和统计能力。
- 迁移必须可在已有 SQLite 数据库上运行：创建默认展示分组、添加分组外键并回填既有密钥、建立转换关系及唯一索引。
- 迁移顺序须保证外键和默认组可用；对已有密钥的回填应幂等或受唯一默认组约束保护。
- 不改变现有 AI 终端“每工具服务商”数据模型及激活规则；仅新增网关密钥来源关系。

## 范围外事项

- 不重构 AI 终端工具的既有服务商数据模型或激活规则。
- 不改变网关密钥认证协议、RootKey 加密算法或历史请求日志结构。
- 不为默认列表提供软删除记录管理或恢复工作流。
- 不将完整密钥写入列表、搜索索引、日志、审计展示或前端持久化状态。

## 假设

- 服务商名称继承密钥名称。
- 完整网关密钥仅在后端转换或用户显式复制时解密。
- 转换使用系统生成的网关地址及合法、无冲突的工具标识。
- 软删除记录不出现在默认列表。
- 工具集合固定为 `claude`、`codex`、`gemini`、`opencode`；前三者每工具至多一个 active，OpenCode 可有多个 active。
