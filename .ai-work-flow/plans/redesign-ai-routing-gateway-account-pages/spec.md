# AI 路由网关账号页面重设计规格

## 规格元数据

- plan-id: `redesign-ai-routing-gateway-account-pages`
- status: `approved`

## 问题陈述

账号池当前需要采用更适合 AI 终端服务商管理的列表与详情体验，同时保持账号池与 AI 终端服务商数据的隔离，并明确凭据、模型映射和价格的安全边界及保存一致性。

## 目标与成功标准

- 账号池列表以 AI 终端服务商式卡片展示账号、凭据类型、API 地址与模型映射信息，并可覆盖 API Key、OAuth、启用与禁用映射及映射溢出情形。
- API Key 账号可完成新增与编辑，且新增失败不留半成品、编辑失败保留原数据。
- 新增 API Key 账号默认拥有完整的同名模型映射和继承的官方价格。
- 明文 API Key 仅在详情专用请求和页面出现，不进入列表、Bootstrap、日志或错误信息。
- 前端交互及后端行为具备对原子保存、价格继承和密钥边界的验证。

## 用户与用户故事

- 作为账号池管理员，我需要在列表中快速识别账号名称、认证类型、API 地址及模型映射状态，以便管理可用上游账号。
- 作为账号池管理员，我需要在专属页面完整配置 API Key 账号的基础信息、连接配置、模型映射和价格，以便精确控制上游服务。
- 作为账号池管理员，我需要查看 OAuth 账号的只读详情，以便了解其元数据、映射和官方价格而不改变其授权状态。
- 作为账号池管理员，我需要在保存失败后保留已输入内容并获得明确错误定位，以便修正问题后重试。

## 功能需求

- 账号池列表采用 AI 终端服务商式卡片布局。每张卡片展示账号名、API Key 或 OAuth 标签、API 地址和模型映射；OAuth 的 API 地址显示为 `-`。
- 卡片展示全部模型映射状态，禁用项必须有明确标记。映射超过 3 项时，显示前 3 项及“其余 N 项”。
- 点击卡片主体或编辑按钮进入该账号的专属详情页；启用、停用、排序和删除操作保留在列表中；新增按钮进入新增专属页。
- 页面使用应用内部的列表/详情模式，不新增 URL 路由或深链接。
- API Key 账号的新增和编辑共用完整表单，覆盖所有现有账号字段、连接配置、模型映射及价格。
- 官方模型在表单中固定为每模型一行。上游模型默认与官方模型同名，可改名或禁用，但不可新增或删除模型行。新增官方模型时，自动补齐默认同名映射。
- 每个模型支持输入、输出、缓存读取和缓存写入四类价格，单位为 USD/百万 Token。默认价格继承官方值，仅保存用户改动的字段；每个模型可恢复官方价格。禁用映射不得清除既有映射或价格。
- API Key 账号的新增和编辑必须原子保存：任一基础字段、凭据、映射或价格保存失败时，整体不生效。
- 编辑 API Key 账号时，页面直接明文显示完整 API Key。明文仅限详情专用请求和该页面，不得出现在列表、Bootstrap、日志或错误信息中。
- OAuth 账号不提供新增。现有 OAuth 账号可进入只读详情，展示元数据、完整映射和官方价格；API 地址显示为 `-`，且不提供连接、映射或价格编辑。
- 保存成功后，刷新数据并返回列表，恢复原有筛选状态并显示成功提示；保存失败时保留表单输入。
- 离开存在未保存修改的页面时，必须请求确认。校验或保存错误必须提供顶部汇总、字段级标记，并定位至首个错误。
- 编辑页和列表均支持永久删除，并复用现有确认流程。
- 不恢复 OAuth 授权流程。

## 非功能需求

- API Key 明文的获取、展示与数据边界必须受到严格限制，避免其进入非详情数据载荷、日志和错误信息。
- 账号、凭据、映射和价格的保存结果必须保持一致，不得产生部分写入状态。
- 账号池数据与 AI 终端服务商数据必须持续隔离。

## 范围

- 账号池的列表卡片、API Key 新增与编辑专属页、OAuth 只读详情页。
- 模型映射显示、映射禁用状态、默认同名映射、价格继承与恢复官方价格。
- 新增、编辑、删除、启停、排序、筛选状态恢复、未保存离开确认及错误反馈。
- API Key 明文详情展示及其专用数据边界。

## 接口与数据

- 列表数据不得包含 API Key 明文，且只提供列表展示和操作所需的数据。
- API Key 明文只能通过详情专用请求提供给详情页面；该请求和页面不得将明文传播至 Bootstrap、日志或错误信息。
- API Key 账号保存时，基础字段、凭据、映射及用户改动的价格字段作为一个整体生效或不生效。
- 价格数据区分官方默认值与用户改动值；未改动字段继承官方价格。
- OAuth 详情提供元数据、完整映射与官方价格，且不提供可编辑的连接、映射或价格数据入口。

## 失败模式

- API Key 账号新增或编辑时，任一基础字段、凭据、映射或价格失败，保存整体失败；新增不创建账号，编辑不改变既有账号数据。
- 保存或校验失败时，页面保留用户输入，显示顶部错误汇总和字段级错误，并定位首个错误。
- 用户尝试离开含未保存修改的新增或编辑页面时，必须先确认离开。
- 禁用模型映射时，保留其映射名称与价格数据。
- OAuth 账号不允许进入新增或编辑连接、映射、价格的流程。

## 验收标准

- 列表以卡片展示 API Key 与 OAuth 账号；卡片包含账号名、认证标签、API 地址及模型映射，OAuth 地址为 `-`。
- 映射不超过 3 项时全部可见；超过 3 项时仅显示前 3 项和正确的“其余 N 项”；禁用映射有明确标记。
- 卡片主体和编辑按钮均可进入专属页；新增进入新增专属页；列表仍可执行启停、排序和删除；编辑页也可永久删除并使用现有确认流程。
- API Key 新增和编辑页包含现有账号字段、连接配置、固定模型行、映射及四类价格；不可增删模型行；新增官方模型后自动出现同名映射。
- 每个模型默认继承官方四类价格，仅保存用户改动字段；可恢复官方价格；禁用映射后其名称与价格仍存在。
- 新增 API Key 账号时，默认创建完整同名映射和官方继承价格；任何保存环节失败均不留下半成品。
- 编辑 API Key 账号时，任何保存环节失败均不改变既有账号数据；失败后表单输入保留。
- API Key 编辑详情直接显示完整明文 Key；列表、Bootstrap、日志和错误信息中均不含该明文；OAuth 详情不显示可编辑连接、映射或价格控件。
- OAuth 不可新增，现有 OAuth 详情显示元数据、完整映射、官方价格和 `-` API 地址。
- 保存成功后返回列表、刷新数据、恢复筛选状态并显示成功提示；失败时有顶部汇总、字段标记和首个错误定位。
- 存在未保存修改时离开页面会确认；不新增 URL 路由或深链接；账号池与 AI 终端服务商数据保持隔离，且不恢复 OAuth 授权。
- 前端交互以及后端的原子保存、价格继承和密钥边界均有验证。

## 兼容性与迁移

- 保持应用内部列表/详情模式，不新增 URL 路由或深链接。
- 保持账号池与 AI 终端服务商数据隔离。
- 不恢复 OAuth 授权流程。
- 保留现有 OAuth 账号，并以只读详情方式展示。

## 范围外事项

- 新增 URL 路由或深链接。
- 恢复、创建或重新授权 OAuth 账号。
- 将账号池数据与 AI 终端服务商数据合并或共享。
- 允许在固定官方模型集合外手动新增或删除模型映射行。

## 假设

- 用户已批准在 API Key 编辑详情页直接明文回显完整 API Key；该行为不使用遮罩替代。
- 现有永久删除确认流程可供列表与编辑页复用。
