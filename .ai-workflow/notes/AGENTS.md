# Agent Notes instructions

Read `README.md` in this directory explicitly before creating, changing or reviewing notes. It is the single source for note format, lifecycle, supersession and archive governance.

Work only on the relevant notes and governance files in the task's authorized scope. Before adding a note, identify related active records within scope and report their full, partial or no supersession disposition; handle each identified disposition in the same change under `README.md`. Read `implemented/AGENTS.md` when maintaining delivered decisions and `archived/AGENTS.md` before archive work. Return a bounded support request when required related records are outside scope.
