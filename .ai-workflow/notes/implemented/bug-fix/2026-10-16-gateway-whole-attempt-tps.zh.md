# Agent Note: Gateway Whole-Attempt Average TPS

Status: implemented

[English](2026-10-16-gateway-whole-attempt-tps.md) | 中文

## Problem

请求日志的 Average TPS 曾用一次尝试有效且被显式上报的累计输出 token 数除以未取整的首输出到结束生成窗口。该除数本身并不真实：上报计数是整次尝试的属性，而可见的流式窗口可能只占其一小部分，于是短窗口配上完整计数会得出高出数百倍的速率。已记录的这次尝试为 41.830 秒整次尝试、1739 个输出 token、41622.7707 毫秒首字延迟，旧值存储 8449.763198666167 t/s，而整次尝试速率为 1739 / 41.83 = 41.57303370786517 t/s（显示 41.57）。该失配的具体物理来源——例如可见流未体现的传输缓冲或隐藏推理——未经证实，此处不作断言。变更还必须保持既有可空列与旧代码行可读，并保持未测量值与测量到的零可区分。

## Decision

平均 TPS 为一次尝试有效且被显式上报的累计输出 token 数除以未取整的整次尝试单调间隔，即从尝试起点到尝试结束，而不是首输出到结束的生成窗口。首字延迟不变：仍是起点到首个有意义输出的间隔；整次尝试间隔现在也包含输出前等待。不施加任何 TPS 上限、下限或阈值。

速率仍需一次可测量的尝试：必须观测到有意义上游输出且上报输出计数有效。整次间隔为零或负时没有 TPS；只要整次间隔为正，首个输出与尝试结束重合仍可测量。正间隔上的显式零计数为 `0.00 t/s`，而缺失、null 或畸形计数保持未知、绝不变为零。

持久化形态不变：仍是 serde 默认的 `first_token_ms` 与 `avg_tps` 字段，以及可空 `first_token_ms REAL` 与 `avg_tps REAL` 列。读取改为复投影速率而非信任存储数值：在 `record_from_row` 中，存储 `avg_tps` 非空且 `duration_ms` 为正的行投影为 `output_tokens / (duration_ms / 1000)`，存储 `avg_tps` 为空则保持不可用。存储列、数据库字节与表结构绝不改写，`first_token_ms` 按存储值投影，历史值绝不回填。非流式资格、有意义输出判定、按尝试的观察者生命周期以及计费、费用与缓存算术均不变。

## Alternatives considered

- 保留首输出到结束的生成窗口除数：未采纳，因为相对于上报计数过短的可见窗口会把速率抬高数个数量级，如已记录尝试的 8449.76 t/s 对 41.57 t/s 所示；上报计数是整次尝试的量，需要整次尝试作分母。
- 给 TPS 设上限、钳制或下限：未采纳，因为任何此类边界都会呈现一个臆造的数字而非真实商值；修复报告真实速率，并把不可测量的尝试保持为不可用。
- 回填或改写历史行，或新增迁移或表结构版本：未采纳，因为缺陷只在于速率的推导方式，所以存储列与数据库保持不动，历史行改为在读取时复投影。
- 在上报计数缺失时从文本长度推导 token 数或速率：未采纳，因为文本长度不是上报计数，臆造它会捏造网关从未观测到的数据；未知计数保持未知。

## Consequences

- 请求日志 Average TPS 现反映整次尝试；短的可见流式窗口不再抬高它，已记录尝试显示 41.57 t/s 而非 8449.76 t/s。首字延迟、有意义输出规则、可空列与前端三行展示均不变。
- 已测量的存储行在读取时复投影为 `output_tokens / (duration_ms / 1000)`；存储的 `avg_tps`、数据库字节与表结构不变，没有存储 `avg_tps` 的行保持不可用，测量到的零仍与未知区分。
- 部分取代：本记录仅取代 [Gateway Request Latency: Observed First-Token and Generation TPS](../feature/2026-10-14-gateway-request-latency.md) 的平均 TPS 分母与相关读取复投影预期。该记录保留并交叉链接，其首字、观察者、列、渲染与颜色事实仍然有效。
- 交付状态：行为测试现已通过——`cargo test --manifest-path src-tauri/Cargo.toml ai_gateway::tests::output_timing` 报告 39 通过 0 失败，`ai_gateway::tests::usage_store` 报告 17 通过 0 失败，另有唯一既有 ignored 性能测试；回归 fixture 复投影为 41.573 t/s，而原始存储列保持 8449.763，首字延迟、null、重开、筛选与三协议流行为均有覆盖。本记录不主张任何合并、发布或提交。
