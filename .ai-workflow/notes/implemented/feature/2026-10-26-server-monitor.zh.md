# Agent Note: Server Monitor Collects Linux Resources Through Read-Only SSH Commands with Independent Session Ownership

Status: implemented

[English](2026-10-26-server-monitor.md) | 中文

## Problem

OneSpace 此前无法观察用户已经通过 SSH 访问的 Linux 主机的 CPU、内存、磁盘与网络状态。安装 exporter 或监控 agent 需要远端软件包、监听端口、防火墙修改以及持续维护的服务，这在生产主机上往往不可行，也与项目本地优先、不向远端安装软件的边界冲突。既有的 SSH 隧道、终端与 SFTP 模块各自拥有自己的生命周期与持久化记录；让监控复用这些对象会把互不相关的意图耦合起来，导致停止隧道或关闭终端会悄然停止监控，而监控重连又可能干扰用户的转发意图。监控还必须在页面隐藏时持续采集、在重启后不重放工作，并诚实描述部分或不可用的数据，而不是臆造数值。

## Decision

采集通过 SSH 执行一个固定的、由仓库自有的 `/bin/sh -s` 脚本。脚本只读取 `/proc`、执行 `LC_ALL=C df -l -P -k -T` 并使用 `uname`、`cat` 与 `sleep`；任何用户字段都不会被插值进远端程序文本。输出按命名分段封装，使 Rust 能独立解析每个来源，stderr 合并到通道输出，检查退出状态，并以 15 秒截止时间约束一次采集。主机上不存在 exporter、agent、已安装服务、HTTP 指标端点或转发端口。该功能仅支持 Linux，并只降级那些命令或字段不可用的资源。

监控连接通过 `src-tauri/src/ssh_tunnels/monitor_transport.rs` 中的窄适配器获得独立所有权。它复用既有 SSH 配置解析、host-key 校验与认证行为，但只拥有自己的命令会话，绝不创建、启动或修改已保存隧道、终端或 SFTP 记录。周期模式为每个目标保持一个持久会话，每次采集运行一个命令通道，并显式发送 30 秒空闲 keepalive；采集与 keepalive 共用同一互斥锁，因此自有会话绝不会同时执行两个操作。每日模式、暂停目标的手动采集以及草稿连接测试都使用全新的一次性会话，并在尝试后关闭。损坏的传输会被丢弃，并可在下一个普通触发时重连；认证、host-key 与配置失败则保持阻塞，直到显式重试或编辑。

进程自有的调度器独立于页面可见性运行。全局最多同时进行四个采集，每个目标至多有一个进行中的采集；手动采集与计划采集冲突时会共享结果。周期模式在启动、激活、恢复与启用自动采集时采集，随后在采集完成时重新计时。每日模式只武装未来的本地时间：启动、保存、创建目标以及在某个时间点当时或之后恢复都不会重放该时间点。在任何网络操作之前，调度器会先在 SQLite 中持久认领目标的本地日期与 `HH:mm` 时段，因此重复 tick、重启与时钟回拨都无法让该时段被尝试两次；认领写入失败时不会建立连接。时段仅在其一分钟窗口内被接受，错过的时段会被跳过而不是补采，夏令时前进造成的不存在时间会被跳过，回拨造成的重复时间最多执行一次。修剪只删除当前本地日期之前的认领，因此保留期变化不会让当天时段重新启用。

指标只来自采集器在同一次执行中取得的两次采样。CPU 总时间由 user、nice、system、idle、iowait、irq、softirq 与 steal 组成，总量中排除 guest 与 guest_nice，使用率为 `100 × (Δtotal − Δidle − Δiowait) / Δtotal`。内存已用为 `MemTotal − MemAvailable`。磁盘数值来自本地持久挂载，排除 `proc`、`sysfs`、`tmpfs`、`devtmpfs`、`overlay` 与 `squashfs`，挂载绝不求和。网络速率按网卡分别用计数器增量除以同一次采集内真实的 uptime 正差值，排除 `lo`，网卡之间绝不求和。无法推导的值保持不可用而不写成零；至少有一个可用资源的采集为部分成功，非 Linux 主机、没有可用资源、脚本失败或整体超时则失败。

配置与历史都位于配置档本地。目标与设置保存在使用应用主密码原子写入的加密 `server_monitor.enc.json` 中；无法读取或解密的文档会被报告且绝不覆盖。样本与时段认领保存在 `server_monitor.db`。密码只保留在加密记录内，安全视图只暴露是否存在密码。两个文件都不会加入 iCloud 或 Git 同步。设置默认为启用自动采集、周期模式、五分钟、`09:00` 与七天保留，并在前端与后端严格校验而不静默修正；只有当前模式控制调度，非活动模式的数值会保留。

代次失效把调度器与用户意图绑定。暂停、删除、连接来源变化、模式变化、全局禁用与应用关闭都会递增对应目标的代次，使自有会话失效并关闭，并让迟到结果在发布、持久化或满足手动刷新之前被拒绝。替代所有者会等待旧目标所有者释放其会话。

## Alternatives considered

- 安装 exporter 或监控 agent：否决，因为它需要远端软件包、服务、监听端口与防火墙修改，并且违背项目不向远端安装软件的边界。
- 读取 HTTP 指标端点或开放转发端口：否决，因为它增加主机上的网络暴露与配置，而转发属于已保存的 SSH 隧道而非监控。
- 复用已保存的 SSH 隧道记录承载监控连接：否决，因为隧道拥有持久化的转发身份与用户意图，而监控只需要自己的短生命周期命令会话；耦合二者会让任一生命周期干扰另一方。
- 将整个 SSH 架构重构为统一的通用连接服务：否决，因为交付的窄适配器在不改变无关隧道、终端或 SFTP 契约的前提下复用了既有配置、认证与 host-key 行为。
- 跨不同计划采样推导网络速率：否决，因为间隔可能被暂停、延迟、重启或比展示所声称的更长；速率只使用一次采集内约一秒的窗口。
- 把磁盘挂载或网卡求和为单一总量：否决，因为多个挂载可能描述同一设备，而网卡承担不同角色；工具改为命名一个挂载与一个可切换网卡，而不是臆造聚合值。
- 把未知字段当作零：否决，因为零是真实测量值；不可用值保持不可用，并产生部分成功或失败状态。
- 在睡眠或退出后补采错过的每日时段：否决，因为迟到的批次会歪曲观测时间，并可能意外认证大量主机；错过的时段会被跳过，只武装未来时间。
- 以明文存储凭据或通过快照暴露凭据：否决，因为配置存储已提供主密码加密，事件也必须可安全消费；只暴露密码存在性。
- 为趋势图新增图表依赖：否决，因为既有的轻量 SVG 历史已足够，并可避免新的运行时依赖。
- 轮询隐藏页面或从导航触发远端工作：否决，因为调度属于后端进程，隐藏视图不得发起页面查询或重复采集工作。

## Consequences

- Server Monitor 工具可从 Hub 与启动台访问，提供持久目标列表、四张指标卡、网卡选择器、感知缺口的 24 小时/七天历史、新增/编辑/删除/测试/暂停/恢复/立即采集操作，以及 Services → Server Monitor 设置区块；其保存、重置与脏状态独立于其他区块。
- 周期模式为每个目标拥有一个持久会话，串行发送 30 秒 keepalive 并在每次完成后重新计时；每日模式每次采集拥有一个一次性会话，时间点之间不保留会话。全局最多同时进行四个采集，每个目标单飞，手动冲突共享计划结果。
- 每日调度只面向未来且持久：目标/日期/时间认领在网络操作之前写入，可跨重启与时钟回拨保持，受一分钟窗口限制，错过时绝不补采。修剪保留当天与未来认领，因此缩短保留期不会重跑时段。
- 指标保持自包含：CPU、内存、磁盘与按网卡网络值只来自一次采集中的两次样本，不可用字段保持不可用，部分结果会被标注，最后成功快照保留其时间戳与错误，每日模式报告等待而不是把已关闭会话当作离线。
- 目标、凭据与设置加密保存在配置档本地的 `server_monitor.enc.json`；样本与认领保存在本地 `server_monitor.db`。安全状态与事件不含密码，两个文件都不同步，无法读取的配置绝不会被默认值替换。
- 回滚是增量且本地的：退出应用会释放自有会话，回退该功能会保留两个文件供以后重装，旧版本二进制会忽略它们，且没有安装任何远端服务或配置。受控真实 SSH/Linux 冒烟已在本地 Docker Debian 目标 `127.0.0.1:2222`（用户 `monitor`）上执行，两个 ignored 冒烟测试均通过：持久采集在同一次认证上完成三次采集，一次性会话在每次采集时认证并断开，周期采集建立了持久连接，暂停与切换每日模式使已建立连接归零，重新启用与恢复周期模式又建立连接并产生新样本，关闭应用会关闭连接；容器日志记录 5 次 accepted-password 认证与 5 次断开。打包应用在 800×600 与 1440×900、中英文、明暗主题下的原生视觉检查未验证，用户已将其作为有界记录缺口接受，而不是通过。
- 取代关系评估：[Toolbox Plugin Registry Replaces Hand-Maintained Tool Lists](../architecture/2026-09-25-toolbox-plugin-registry.md) 与 [SSH Tunnel Reconnect Resilience Uses a Persistent Supervisor, a Round-Trip Probe, a Desired-Running Watchdog and a Wake/Window Retry Poke](../bug-fix/2026-09-30-ssh-tunnel-reconnect-resilience.md) 均未被取代。注册表决策仍是工具表面的来源，隧道监管决策仍是隧道意图与监管的来源；监控新增自己的适配器与记录，不改变任一契约。
