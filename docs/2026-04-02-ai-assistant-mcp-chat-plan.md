# AI 助手 MCP 检索统一方案

## Summary
- 删除遗留 [Agents.tsx](/Users/yuqiyu/AiHistorys/one-space/onespace-app/src/components/Agents.tsx)。
- 助手配置改为从已管理 MCP 中可视化多选，并展示每个 MCP 的能力、影响、工具预览。
- 新建助手默认补齐并选中 `exa`、`context7`。
- 聊天中的联网/检索能力统一走 MCP：
  - `exa` 负责通用联网搜索
  - `context7` 负责文档/代码文档检索
- 不再保留独立的内建 `web_search` 执行实现；聊天框里的“联网搜索”图标保留，但语义改成“搜索类 MCP 总开关”。

## Key Changes
- MCP 元信息
  - 在 [mcp_templates.rs](/Users/yuqiyu/AiHistorys/one-space/onespace-app/src-tauri/src/mcp_templates.rs) 为模板增加结构化字段：
    - `category`
    - `capability_summary`
    - `capability_tags`
    - `impact_tags`
    - `impact_note`
  - 至少区分分类：
    - `search`
    - `docs`
    - `workspace`
    - `integration`
    - `automation`
  - 新增 `exa` 模板，分类为 `search`
  - 现有 `context7` 模板分类为 `docs`
  - 对手工创建或非模板 MCP，用 transport / trust / env / headers 自动推导通用影响标签
- 助手 MCP 选择器
  - 新增命令 `workspace_assistant_mcp_catalog()`
  - 返回：
    - 全部已管理 MCP
    - 默认 `exa/context7`
    - 能力摘要
    - 影响标签
    - 工具预览
    - 工具预览状态
    - MCP 分类
  - 在 [AiWorkspace.tsx](/Users/yuqiyu/AiHistorys/one-space/onespace-app/src/components/AiWorkspace.tsx) 中把手输 `mcp_server_ids` 改成卡片式多选器
  - 每个条目展示：
    - 名称
    - 一句话能力摘要
    - 能力标签
    - 影响标签
    - 工具数量与前几个工具名
    - 预探测失败时的降级提示
  - 已选区域显示名称 + 摘要，不显示裸 ID
  - 新建助手自动带上 `exa/context7`；已有助手不自动迁移
- 工具预览
  - 选择器打开后异步执行 `initialize + tools/list`
  - 结果缓存本地，附带 `checked_at`
  - 失败时仅隐藏工具预览，不影响选择
- 聊天 MCP 运行时
  - 新增运行时模块，例如 `src-tauri/src/mcp_runtime.rs`
  - 支持 `stdio`、`http`、`sse`
  - 在 [ai_assistant.rs](/Users/yuqiyu/AiHistorys/one-space/onespace-app/src-tauri/src/ai_assistant.rs) 中：
    - 依据 `assistant.mcp_server_ids` 装载 MCP
    - 执行 `initialize + tools/list`
    - 将工具注册进 `available_tools`
    - 将模型 tool call 路由到 `tools/call`
    - 将结果写回现有 `tool_calls` 流
  - 工具命名统一为 `mcp__{config_key}__{tool_name}`
  - Exa 返回结果额外映射到 `sources`
- “联网搜索”图标语义调整
  - 保留现有 `Globe` 按钮位置
  - 文案建议改成“联网检索”或保留图标但增加 tooltip
  - 它只控制 `category=search` 的 MCP 是否可暴露给模型
  - 关闭时：
    - `exa` 等搜索型 MCP 不进入 `available_tools`
  - 开启时：
    - 已绑定的搜索型 MCP 可用
  - `context7` 这类 `docs` MCP 不受该开关影响
- 删除独立 web_search
  - 从 [ai_assistant.rs](/Users/yuqiyu/AiHistorys/one-space/onespace-app/src-tauri/src/ai_assistant.rs) 移除独立 `web_search` 工具定义与相关提示逻辑
  - 不新增单独的内建搜索实现，避免与 `exa MCP` 双轨并存
  - `web_search_enabled` 保留字段，但语义改为“搜索类 MCP 开关”，不再代表单独内建搜索能力

## Public Interfaces
- 新增 Tauri 命令：
  - `workspace_assistant_mcp_catalog()`
  - `mcp_tool_preview_refresh(server_ids?)`
- 新增前端类型：
  - `ManagedMcpServerCatalogItem`
  - `McpCategory`
  - `McpImpactTag`
  - `McpToolPreview`
- 现有 `workspace_assistant_upsert` 入参保持不变，继续保存 `mcp_server_ids: string[]`
- 现有 `web_search_enabled` 字段继续保留，但改为搜索类 MCP 总开关语义

## Test Plan
- Rust 单测
  - `exa/context7` 默认创建幂等
  - 模板元信息能正确映射分类、能力、影响
  - 非模板 MCP 能自动生成影响标签
  - `tools/list` 预探测成功/失败都能正确返回状态
  - `stdio/http/sse` 的 `initialize/tools/list/tools/call` 行为正确
  - 搜索类 MCP 在总开关关闭时不会进入 `available_tools`
  - `docs` 类 MCP 不受总开关影响
  - Exa 结果能映射到 `sources`
- 前端验证
  - 新建助手默认已选 `exa/context7`
  - 选择器中每个 MCP 能看到能力、影响、工具预览
  - 工具预览失败时仍可选择
  - 聊天中关闭“联网检索”后，Exa 不可调用
  - 聊天中开启“联网检索”且绑定 Exa 时，可联网搜索并显示来源
  - 聊天中绑定 `context7` 时，即使关闭联网检索，文档检索仍可用
- 回归命令

  - `npm run build`
  - `cargo test`
