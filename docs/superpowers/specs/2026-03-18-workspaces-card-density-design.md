# Workspace Card Density Design

## Goal

在不删减工作空间关键信息的前提下，缩小工作空间列表卡片尺寸，让一屏能容纳更多卡片，同时保持信息层级清晰、操作路径直接。

## Approved Direction

- 保留标题、来源、根路径、描述、标签、会话数、最后活跃时间、编辑/复制/删除操作和 `New AI Session` 主按钮。
- 通过收紧卡片内边距、压缩垂直间距、缩小局部字号与按钮尺寸来提升密度。
- 保持现有卡片式视觉，不切换成表格或列表行。

## Layout Changes

- 卡片整体从宽松的块状布局改成更紧凑的四段结构：头部、描述、标签、底部信息与主操作。
- 顶部标题区保留来源 badge，并让编辑/复制/删除操作以更紧凑的图标按钮呈现。
- 根路径改为更薄的辅助信息条，降低高度但保留可读性。
- 底部将会话数和最后活跃时间整理成紧凑信息区，减少空白分隔。
- 主操作按钮缩成更小的次高优先级按钮，但继续保持明确主视觉。

## Responsive Rules

- 移动端继续单列。
- 中屏保持双列。
- 大屏延续三列。
- 超宽屏增加到四列，利用缩小后的卡片尺寸提升单位面积信息量。

## Constraints

- 不隐藏标签。
- 不删除描述字段。
- 不把主操作改成悬浮菜单。
- 不改动详情页和工作空间数据结构。
